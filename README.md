# LinkedIn AI Post Generator using MCP

---

# Overview

This project explores how AI workflows can simplify and automate professional content creation on LinkedIn using MCP (Model Context Protocol) integrations.

The idea behind this workflow was simple:
instead of manually drafting, formatting, attaching images, and publishing LinkedIn posts, I wanted to understand how AI tools and MCP integrations could streamline the entire process inside Cursor AI IDE.

Using Cursor AI, MCP integrations, Cloudinary, and prompt engineering, I created a workflow capable of generating LinkedIn-ready content, attaching images, previewing posts before publishing, and automating repetitive social media tasks.

What made this project interesting for me was not just the automation itself, but understanding how modern AI tools can collaborate together in a practical workflow.

---

# Problem Statement

Creating professional LinkedIn posts consistently can become repetitive:
- drafting content
- formatting posts
- uploading images
- reviewing before publishing
- maintaining consistency

This project demonstrates how MCP integrations can reduce that friction using AI-assisted workflows.

# Workflow Architecture

## 1. MCP Integration
Configured MCP tools within Cursor AI IDE to enable external workflow integrations.

## 2. AI Prompt Generation
Designed structured prompts for generating professional LinkedIn content.

## 3. Image Hosting
Uploaded project-related assets to Cloudinary and generated public image URLs.

## 4. Preview Workflow
Implemented a verification-first workflow to preview content before publishing.

## 5. LinkedIn Automation
Integrated LinkedIn posting workflow using MCP-connected automation tools.
