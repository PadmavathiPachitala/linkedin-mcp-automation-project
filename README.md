# LinkedIn AI Post Generator using MCP


---

# Project Overview

This project demonstrates an AI-powered LinkedIn automation workflow built using **Cursor AI IDE** and **MCP (Model Context Protocol)** integration.

The workflow enables users to:
- Generate professional LinkedIn posts using AI
- Integrate AI workflows through MCP tools
- Attach images using Cloudinary
- Preview posts before publishing
- Automate LinkedIn content creation efficiently
